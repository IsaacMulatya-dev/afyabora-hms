Welcome to afyabora Hospital Management System

About This Project

afyabora is a hospital management system I built to help clinics and hospitals manage patients, pharmacy, appointments and more.

How to Run the Project

You can work on this project in a few ways:

1. On Your Own Computer

Make sure you have Node.js and npm installed.

```sh
Clone the repository
git clone <YOUR_GIT_URL>

Go into the project folder
cd <YOUR_PROJECT_NAME>

Install all dependencies
npm install

Start the development server
npm run dev
```

Open your browser and go to [http://localhost:5173](http://localhost:5173) to see the app.

### 2. Edit Directly on GitHub

- Find the file you want to change.
- Click the pencil icon to edit.
- Commit your changes.

3. Use GitHub Codespaces

- Go to your repo on GitHub.
- Click the green "Code" button.
- Choose "Codespaces" and start a new one.
- Edit files and commit when done.
