# afyabora Hospital Management System

Welcome to afyabora! This system helps manage hospital operations like patient records, pharmacy, appointments, and more.

## Features

- Patient registration and management
- Pharmacy module for dispensing medicine
- Appointment scheduling
- Staff and user management
- Secure sign-in and authentication

## Installation

1. Clone the repository:
   ```
   git clone <your-repo-url>
   ```
2. Install dependencies:
   ```
   npm install
   ```
3. Start the development server:
   ```
   npm run dev
   ```

## Usage

- Open your browser and go to [http://localhost:5173](http://localhost:5173)
- Sign in with your credentials
- Use the dashboard to access different modules
